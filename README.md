# enjmin card game

Player
- HP 20
- 7 cards hand
- 30 cards deck
- 3 starting manas (+1 per turn) uncapped

Cards
- Cost
- Monster wait one turn before attacking
- ATK / DEF

Rules :
- Draw a card
- Place costest cards first
- Cards always face (attacks enemy player)

Cards :
- Cost : floor( (ATK + DEF) / 2.0 ) + skills cost
- Max cost : 6
